## 🚀 Bonus: Hospedaje de la Página Web a través de GitHub Pages (10 Firmas)

* **URL Pública del Portafolio:** [https://monx030.github.io/4C-Aplicaciones-WEBB/](https://monx030.github.io/4C-Aplicaciones-WEBB/)
* **GitHub URL del Repositorio:** [https://github.com/MonX030/4C-Aplicaciones-WEBB](https://github.com/MonX030/4C-Aplicaciones-WEBB)

### 1. Procedimiento Realizado
1. **Configuración de visibilidad:** Se cambió la visibilidad del repositorio a pública para habilitar el servicio gratuito de GitHub Pages.
2. **Despliegue del sitio:** En la sección *Settings > Pages*, se seleccionó la rama `main` y la carpeta raíz (`/ root`) como fuente de publicación.
3. **Manejo de rutas:** Se creó un archivo de redirección `index.html` en la raíz del repositorio que direcciona automáticamente al usuario hacia la subcarpeta `practica 03/` donde habita el portafolio personal.

### 2. Dificultades Encontradas
* Debido a que el proyecto se encuentra organizado dentro de una subcarpeta específica (`practica 03/`), al acceder al dominio principal de GitHub Pages no cargaba el portafolio de forma directa por defecto.

### 3. Soluciones Implementadas
* Se maquetó e integró un archivo `index.html` en la raíz del proyecto con la etiqueta de redirección `<meta http-equiv="refresh">`, asegurando que el acceso público al enlace web principal envíe inmediatamente al portafolio sin requerir la escritura manual de la ruta.
